# 🐣 小鸡专注 (Little Chick Focus)

一个 Windows 桌面专注计时器：用一只戴圆框眼镜、捧着数学书的小鸡陪你学习，记录每天的专注时长和微信使用时间。

## 功能

- **专注计时**：填写事项 → 开始专注，黑色进度环一小时转满一整圈（填充式），可暂停/继续
- **小鸡浮窗**：收起到透明小浮窗继续计时，时间胶囊贴在小鸡头顶，可随意拖动
- **微信提醒**：每次打开微信前台连续超过 1 分钟，屏幕中央弹出提醒（每次都会提醒，非累计）
- **每日记录**：专注明细、微信前台时长自动保存，打开网页即可查看每日事项与历史
- **开机自启**：通过启动文件夹快捷方式开机自动运行（启动即收起到小鸡球）

## 运行

1. 双击 `start.bat`（使用 pythonw 后台启动，不弹黑框）
2. 依赖：Windows + Python 3 + Tkinter（标准库自带）

## 数据

记录保存在本机：`%LOCALAPPDATA%\LittleChickFocus\sessions.json`
（不包含任何联网上报，纯本地存储）

## 文件说明

| 文件 | 说明 |
|---|---|
| `focus.py` | 主程序（Tkinter 实现，DPI 自适应） |
| `start.bat` | 启动脚本 |
| `index.html` | 每日记录网页（由内置本地服务器提供） |
| `chick.png` | 浮窗小鸡贴纸（马克笔手绘风，头顶两簇毛） |
| `make_chick.py` | 贴纸抠图/合成脚本 |

## 快捷键

- `Esc`：收起到小鸡球
- 浮窗左键单击：展开主窗口
- 浮窗右键：打开每日专注记录
